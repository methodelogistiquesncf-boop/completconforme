Guide utilisateur

Mode opératoire
ComplèteConforme

Toutes les étapes pour réaliser un contrôle de conformité de kit, consulter l'historique, analyser les statistiques et administrer l'application.

Agents terrain Responsables Administrateurs
01

Connexion à l'application

L'accès à ComplèteConforme nécessite un compte créé par un administrateur. Vous recevez vos identifiants par e-mail.

Étape 1
Renseigner les identifiants
Saisissez votre adresse e-mail professionnelle et votre mot de passe. Cliquez sur l'icône 👁 pour afficher le mot de passe en clair si besoin.
Étape 2
Se connecter
Cliquez sur Se connecter → ou appuyez sur Entrée. L'application s'ouvre directement sur l'onglet Terrain.
Après plusieurs tentatives échouées, le compte est temporairement verrouillé. Contactez votre administrateur si vous êtes bloqué.
02

Vue calendrier

Le calendrier est l'écran d'accueil de l'onglet Terrain. Il affiche les 7 jours de la semaine et le nombre de kits à contrôler pour chaque journée, mis à jour en temps réel.

À contrôler Incomplet Conforme
Navigation
Changer de semaine
Utilisez les flèches ‹ et › pour passer à la semaine précédente ou suivante. Le bouton Aujourd'hui recentre immédiatement sur la semaine en cours.
Filtres
Filtrer par emplacement ou WMS
Le champ Emplacement filtre par code d'emplacement (ex : ETKI.0070301) ou par numéro d'engin. Le champ WMS filtre par zone de remontage — pré-rempli sur MAG2-E-PRE par défaut.
Les filtres s'appliquent instantanément, sans rechargement des données.
Sélection
Voir les kits d'une journée
Cliquez sur une case du calendrier pour afficher la liste des kits de cette date dans le panneau du bas. Ils sont triés par priorité : incomplets d'abord, puis à contrôler, puis conformes.
03

Contrôle d'un kit

Depuis la liste des kits, cliquez sur une carte pour ouvrir la fiche de contrôle. Chaque composant du kit est listé avec sa quantité requise.

1 Ouvrir le kit
→
2 Saisir les quantités
→
3 Valider le statut
Étape 1
Saisir les quantités comptées
Pour chaque composant, entrez la quantité physiquement comptée dans le champ de saisie à droite. La ligne passe en vert si la quantité est conforme, en rouge en cas d'écart. Un champ laissé vide signifie "non renseigné".
Étape 2 — Option A
Valider "Conforme" ✅
Appuyez sur le bouton Conforme si tous les composants sont présents en quantité correcte. Si des articles n'ont pas été renseignés, une fenêtre de confirmation est affichée avant l'enregistrement.
Si un composant présente un écart de quantité (ligne rouge), la validation "Conforme" est bloquée. Corrigez la saisie ou utilisez le statut "Incomplet".
Étape 2 — Option B
Valider "Incomplet" ⚠️
Appuyez sur le bouton Incomplet si un ou plusieurs composants manquent ou sont en quantité insuffisante. Le kit apparaît en orange dans le calendrier et les listes.
Après validation, l'application revient automatiquement au calendrier. Le statut du kit est mis à jour en temps réel pour tous les utilisateurs connectés simultanément.

Cliquez sur n'importe quelle ligne de résultat pour ouvrir directement la fiche de contrôle du kit dans l'onglet Terrain et réaliser un nouveau contrôle.

06

Onglet Import Administrateurs

L'onglet Import permet de mettre à jour les emplacements autorisés et d'importer de nouveaux kits depuis un fichier Excel. Les fichiers sont envoyés automatiquement vers le dépôt GitHub et déclenchent le pipeline d'intégration.

Onglet Emplacements
Mettre à jour les emplacements autorisés
Déposez le fichier emplacements_autorises.txt (un identifiant par ligne, lignes commençant par # ignorées) dans la zone de dépôt ou cliquez pour parcourir vos fichiers. Le fichier est envoyé vers GitHub et la liste active est mise à jour.
Le nom du fichier doit être exactement emplacements_autorises.txt. Tout autre nom sera refusé.
Onglet Import kits
Importer un fichier Excel de kits
Déposez un fichier .xlsx, .xls ou .csv dans la zone de dépôt. Le fichier est envoyé dans le dossier imports/pending/ du dépôt GitHub, ce qui déclenche automatiquement le pipeline de traitement GitHub Actions.
Les noms de fichiers contenant des accents, espaces ou caractères spéciaux sont automatiquement normalisés avant l'envoi. Ex : Kit été 2024.xlsx → kit-ete-2024.xlsx.
Suivi pipeline
Surveiller le traitement en temps réel
Après l'envoi, un panneau de suivi s'affiche avec 4 étapes : Réception → Traitement → Import Firestore → Finalisation. Attendez la confirmation ✅ avant de fermer la page.
En cas d'échec pipeline (étape rouge), un lien vers GitHub Actions est fourni pour consulter les logs détaillés.
La configuration du token GitHub se fait depuis l'onglet Admin (protégé par code PIN). Seul l'administrateur système y a accès.
07

Gestion du compte

Chaque utilisateur peut consulter les informations de son compte et modifier son mot de passe depuis l'onglet Profil.

Accès
Accéder au profil
Cliquez sur l'initiale de votre e-mail en haut à droite de l'écran. Vous accédez à votre adresse e-mail, identifiant unique, date de création du compte et date de dernière connexion.
Sécurité
Changer le mot de passe
Renseignez votre mot de passe actuel, puis le nouveau mot de passe deux fois. La barre de force s'affiche automatiquement et indique si votre mot de passe est suffisamment sécurisé.
Minimum 6 caractères requis. Recommandé : 12 caractères ou plus, avec majuscules, chiffres et caractères spéciaux (score "Très fort").
Déconnexion
Se déconnecter
Cliquez sur Se déconnecter dans le menu en haut à droite (accessible depuis n'importe quel onglet). Une fenêtre de confirmation est affichée avant la déconnexion effective.
